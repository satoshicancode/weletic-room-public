# Weletic Security Policy

## Supported Versions

Security fixes target the current Weletic `main` branch. Older branches, archived
snapshots, and upstream Dub releases are not supported by this policy.

## Reporting a Vulnerability

Report Weletic vulnerabilities privately to the repository owner at
[hiro@myjp.com](mailto:hiro@myjp.com). Do not open a public issue or pull request
containing exploit details, credentials, or customer data.

Include the affected version or commit, a description of the impact, and minimal
reproduction steps using synthetic data. Do not access other users' data, disrupt
services, or test third-party systems without their permission.

This project does not promise a fixed response time or operate a paid bug bounty
program. Coordinate any public disclosure with the maintainer while a report is
being assessed and addressed.

This policy applies to Weletic. Dub's security team does not handle Weletic
reports; reports concerning Dub itself should follow Dub's own security policy.
